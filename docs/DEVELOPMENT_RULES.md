# Правила разработки crypto-bot

Перед добавлением нового функционала:

1. Сначала проверить docs/PROJECT_MAP.md.
2. Выполнить поиск по проекту.
3. Не создавать дублирующие классы и модули.
4. Предпочитать расширение существующего кода.
5. После изменений обновить карту проекта:

python scripts/build_project_index.py

6. Перед каждым коммитом запускать:

pytest -q
python scripts/build_project_index.py --check
